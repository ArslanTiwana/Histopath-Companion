# Voice action registry

Generated by `npm run actions:list`. Risky actions use the persisted confirmation-token flow.

## global

| Action | Risk | Description |
|---|---|---|
| `cancel` | safe | Cancel the pending action |
| `confirm` | safe | Confirm the pending action |
| `go_back` | safe | Return to the previous screen. |
| `navigate` | safe | Open a named app route. |
| `next_case` | safe | Open the next case waiting for grossing. |
| `open_case` | safe | Open a case by case label. |
| `read_screen` | safe | Read a short summary of the current screen. |
| `set_filter` | safe | Change the visible case filter. |
| `set_offline_note` | safe | Set the temporary device-only offline note. |
| `set_voice_command` | safe | Set the typed voice command fallback. |
| `start_listening` | safe | Start the hands-free voice session. |
| `stop_listening` | safe | Stop the hands-free voice session. |
| `submit_voice_command` | safe | Submit the typed command through the voice action router. |
| `toggle_voice_details` | safe | Show or hide recent voice details. |
| `undo_last` | safe | Undo the last safe action |
